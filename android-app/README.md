# Ritmo Offline para Android

Aplicación nativa Android para reproducir música guardada en el teléfono, sin conexión a internet.

## Funciones
- Seleccionar varios archivos de audio con el selector seguro de Android.
- Recordar la biblioteca local entre sesiones mientras los permisos de los archivos sigan disponibles.
- Buscar canciones, reproducir, pausar, anterior y siguiente.
- Reproducción en segundo plano con notificación multimedia y controles compatibles con auriculares/Android.
- Aleatorio y repetición de canción o lista.
- La música no se sube a ningún servidor.

## Descargar el APK
Cada cambio en android-app ejecuta GitHub Actions. Abre la pestaña Actions del repositorio, entra en Build Ritmo Offline APK y descarga el artefacto ritmo-offline-debug-apk. Es un APK de depuración para pruebas personales, no una versión firmada para Play Store.

Requiere Android 7.0 (API 24) o superior. Algunos formatos dependen del soporte de audio de Android.
