# Ritmo Offline 🎵

Reproductor web instalable para escuchar archivos de audio locales sin conexión.

## Funciones
- Selección de múltiples canciones y, cuando el navegador lo permite, carpetas.
- Reproducción, pausa, anterior/siguiente, búsqueda y progreso.
- Aleatorio, repetición, volumen y eliminación de pistas.
- Diseño adaptable a móvil y caché offline de la interfaz (PWA).
- Los archivos se reproducen localmente; no se suben a ningún servidor.

## Probar
Abre la página publicada por GitHub Pages: `https://alejandro2397.github.io/music/`

Para instalar en Android: abre el enlace en Chrome, menú ⋮ → **Añadir a pantalla de inicio** o **Instalar aplicación**. Abre la app una vez con internet para guardar la interfaz en caché.

## Importante
Por privacidad y límites del navegador, esta versión no copia ni guarda los archivos de audio dentro de la app: selecciona las canciones del teléfono cada vez que quieras cargarlas. La reproducción de fondo y el soporte de formatos dependen del navegador/dispositivo. No incluye descargas de música protegida ni streaming de terceros.
